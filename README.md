# 🛒 Zippy Store

### A modern, responsive e-commerce website built with HTML, Tailwind CSS, and JavaScript.

Explore an interactive online shopping experience featuring everyday products, dynamic product listings, category filtering, search functionality, wishlist management, and a shopping cart.

**Live Demo:** [Zippy Store](https://suprio-dev.github.io/Zippy-Store/)

---

## ✨ Features

- Dynamic product listing using the DummyJSON API
- Product search functionality
- Category-based product filtering
- Individual product details page
- Add and remove products from wishlist
- Add and remove products from shopping cart
- Persistent wishlist and cart using Local Storage
- Dynamic wishlist and cart item counters
- Product ratings and reviews display
- Responsive design for different screen sizes
- Interactive toast notifications
- Modern UI with Tailwind CSS

## 🛍️ Website Overview

```text
          Open Zippy Store
                 ↓
          Explore Products
                 ↓
       Search & Filter Products
                 ↓
         View Product Details
                 ↓
        Add to Wishlist / Cart
                 ↓
       Manage Shopping Cart
                 ↓
          Proceed to Checkout
                 ↓
        Checkout Coming Soon!
```

Zippy Store provides a dynamic shopping interface where users can explore products, search through collections, view product details, and manage their wishlist and shopping cart. Product information is fetched from the DummyJSON API, while Local Storage keeps cart and wishlist data persistent across page reloads.
